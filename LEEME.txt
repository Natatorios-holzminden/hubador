HUBADOR — pack liviano para publicar
====================================

Contenido
---------
- index.html  → sitio completo (web + mobile)
- img/        → solo imágenes usadas por index.html

Subir a GitHub Pages
--------------------
1. Creá un repo (ej. hubador) o usá uno existente.
2. Subí SOLO el contenido de esta carpeta (index.html + img/).
   En Settings → Pages → Source: Deploy from a branch → main / (root).
3. La URL quedará tipo: https://TU-USUARIO.github.io/hubador/

Rutas de imágenes (importante)
------------------------------
Usá rutas RELATIVAS, sin barra al inicio:
  BIEN:  img/tomate.jpg
  MAL:   /img/tomate.jpg

Con la barra inicial GitHub Pages busca en la raíz del dominio
y las fotos fallan si el sitio está en un subdirectorio.

Dominio hubador.com
-------------------
- Un solo hogar: apuntá hubador.com (DNS CNAME o A según GitHub)
  a este mismo GitHub Pages.
- Dejá cualquier carpeta/demo "rfb" solo como borrador; no la uses
  como sitio principal del dominio.

Vista local
-----------
Doble clic en index.html, o servir la carpeta:
  python -m http.server 8765
luego abrí http://localhost:8765/
