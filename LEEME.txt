IMPORTANTE — NO alcanza con subir a rfbconstrucciones
-----------------------------------------------------
rfbconstrucciones.com.ar/vconlat/ es OTRO hosting (funciona).
hubador.com apunta a GitHub Pages (u otro host del dominio).
Hay que subir ESTE pack al repo/host que sirva hubador.com.

Pasos (GitHub Pages)
--------------------
1. Abrí el repo que publica hubador.com
   (ej. natatorios-holzminden/hubador).
2. Borrá el index.html viejo del repo (y la carpeta img vieja si existe).
3. Subí TODO el contenido de esta carpeta: index.html + img/
   (arrastrá los archivos, NO otra carpeta adentro).
4. Settings → Pages → Deploy from a branch → main / (root).
5. Esperá 1 minuto a que despliegue.
6. En el teléfono/PC: Ctrl+Shift+R (o borrar caché del sitio).

Cómo verificar que cargó ESTE build
-----------------------------------
- En “Productos / listado” debe verse el texto · u-v3 (no u-v2).
- Ver código fuente (Ctrl+U) y buscar: HUBADOR_BUILD 20260807d
- Cada card debe mostrar: precio + barra + “Faltan X kg” + timer + botón Unirme al grupo
