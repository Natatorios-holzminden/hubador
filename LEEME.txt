Flujo de compra
---------------
1. Mis grupos → Carrito = armá qty / productos (conlatCart). NO es el destino final.
2. Confirmar mi pedido → saca del carrito y guarda en hubadorOrders + hubadorActiveGroups.
3. Cambia a pestaña Activos + toast “Pedido confirmado · lo ves en Grupos activos y en Perfil”.
4. Perfil → Tus pedidos = solo pedidos reales (chip En formación). Sin demos falsos.
5. Auth → Users = quién se logueó. Table Editor → orders = qty (tras correr supabase-orders.sql).

Si no podés ingresar
--------------------
- Dos “Ingresar” (header + título de la página) es normal: el del header abre la misma pantalla.
- Login ≠ registro: si nunca hiciste Registrate, el login falla.
- En Supabase → Authentication → Users: ¿aparece tu email?
- Si dice “confirmá el mail”: confirmá el correo o desactivá Confirm email.
- El toast ahora muestra el error de Supabase en español.

Pasos (GitHub Pages)
--------------------
1. Abrí el repo que publica hubador.com
   (ej. natatorios-holzminden/hubador).
2. Borrá el index.html viejo del repo (y la carpeta img vieja si existe).
3. Subí TODO el contenido de esta carpeta: index.html + config.js + img/ (+ SQL/docs si querés)
   (arrastrá los archivos, NO otra carpeta adentro).
4. Settings → Pages → Deploy from a branch → main / (root).
5. Esperá 1 minuto a que despliegue.
6. En el teléfono/PC: Ctrl+Shift+R (o borrar caché del sitio).
