Hay que subir ESTE pack al repo/host que sirva hubador.com.

Auth — qué falta de tu lado
---------------------------
1. SQL Editor → corré supabase-schema.sql (si no lo hiciste)
2. Auth → Email → desactivá “Confirm email” para probar
3. Probá signup en el sitio → login → recargar sesión
4. Subí este zip de nuevo a hubador.com (index.html + config.js + img/)

Sin keys el sitio queda en modo demo; CON estas keys el demo se apaga.

Pasos (GitHub Pages)
--------------------
1. Abrí el repo que publica hubador.com
   (ej. natatorios-holzminden/hubador).
2. Borrá el index.html viejo del repo (y la carpeta img vieja si existe).
3. Subí TODO el contenido de esta carpeta: index.html + config.js + img/ (+ SQL/docs si querés)
   (arrastrá los archivos, NO otra carpeta adentro).
4. Settings → Pages → Deploy from a branch → main / (root).
5. Esperá 1 minuto a que despliegue.
6. En el teléfono/PC: Ctrl+Shift+R (o borrar caché del sitio).
